# LOL 电竞生涯模拟器 · 从青训到传奇

参照工作区里的「篮球生涯模拟器」制作的英雄联盟电竞版本。纯前端、单机、本地存档，无需服务器。

## 玩法

- 选一个赛区和分路，从 15 岁青训（15-17 岁三季青训）打到退役，18 岁签约进战队
- 天赋有高低：潜力分 S/A/B/C 四档，有人一飞冲天成为第一人，也有人从头碌碌无为；成长不是必然，状态差会停滞倒退，连续摆烂会掉天赋
- 固定节奏：每个职业赛季拆成春季赛 / 夏季赛两个半程，各一次决策；MSI 和全明星挂在春季，世界赛 / 亚运会 / 洲际赛挂在夏季
- 28 岁起可以选择退役，32 岁必须退役
- 转会更多更丰富：实力越高，各大赛区的战队越会来抢人，每次邀约 4-5 支战队可选
- 选队有取舍：报价会显示「预计角色 + 加成」——豪门夺冠/薪资加成但竞争激烈可能坐板凳，平民队核心培养成长加速但薪资低，中游均衡，顶级赛区曝光更高
- 转会可以留队续约；合同 3 年一签，到期后按表现续约——打得好俱乐部主动留人，打得差可能不续约
- 每个决策选项都标注明确影响：可能 +几 能力、有风险扣能力、伤病、禁赛等
- 决胜时刻按分路区分：打野才拼惩戒抢龙，ADC 打团战输出位、中单对决、上单单带、辅助抢视野开团
- 重点赛区：中（LPL）/ 韩（LCK）/ 北美（LCS）三大主赛区，另有外卡赛区可选
- 转会、手伤、冒泡赛、亚运会、全球总决赛，每个决定都算数
- 一生之敌：同分路、同年出道的宿敌陪你斗一辈子，总击杀、冠军、MVP 逐年对位
- 宿敌和对手来自现实选手名单：Faker 六冠王、T1 三连冠、GEN MSI 二连冠、BLG 全华班……按 2025-2026 最新阵容收录
- 梗管够：4396、反向Q、天神下凡、九折水瓶、收徒、舒服了、0-22、八龙珠、十七强、陀螺、送姜、大飞老师……
- 荣誉种类多：常规赛MVP、最佳阵容/二阵、最佳新秀、击杀王、单杀王、补刀王、助攻王、视野王、进步最快、最受欢迎……
- 杯赛覆盖全赛区：德玛西亚杯、韩国杯、欧洲大师杯、北美季前赛、太平洋杯、越南杯、巴西杯、日本杯、拉美杯……
- 每个赛季沉淀生涯高光：场均击杀、KDA、单场五杀、20 杀之夜、世界赛冠军
- 60+ 个决策事件：训练、转会期、全明星、Solo 王、更衣室、网暴、版本更新
- 节奏固定为沉浸式：每个赛季一次决策
- 生涯结束自动生成可保存、可分享的「生涯战绩卡」
- 历史档案：每一局自动留档，随时翻回任意一局的战绩卡
- 称号图鉴：32 个称号，拿到过的显示你当时那句话
- 编号系统：复制本局编号发给朋友，输入编号即可复现同一段生涯

## 运行

任意静态服务器即可（模块脚本需要 http 环境，直接双击打开 index.html 不行）：

```bash
npx serve .
```

然后访问 `http://localhost:8080/lol/`。

## 测试

```bash
node test/sim.js   # 无头生涯流程与确定性测试
```
